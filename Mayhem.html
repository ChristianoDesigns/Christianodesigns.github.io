A set of postcards.

Project:
Mayhem

Year:
2020

Type:
Mark-making

Colours:
CMYK
This set of postcards is designed using several mark making techniques to create an emotional response with the audience. The colour and composition adds tension to the design while the rough imagery gives the postcards a sense of mayhem. The postcards are indented to work together to create an overarching theme of destruction.
4 Postcard examples
Each postcard uses a unique set of mark making techniques which creates lots of intrigue between the collection. The use of a singular spot colour creates a focus on a particular element.
